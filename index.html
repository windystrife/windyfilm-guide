Mọi ảnh đều làm từ file CR2 của một cuộn mẫu (EOS M, EF 50 mm f/1.8 STM, 14/11/2026), qua đúng code Darkroom mà máy chạy, với cài đặt mặc định của phim: Print Scan, Strength 100 %, Grain Normal, Halation Wide (tên cũ "Film"), Bloom Normal, Mist Off. Chọn ảnh A và B, kéo vạch để so, hoặc lật qua lại. "Chi tiết 1:1" là vùng cắt đúng điểm ảnh của file 5184 px, để thấy grain. Every image comes from the CR2 files of one sample roll (EOS M, EF 50 mm f/1.8 STM, 14 Nov 2026), through the same Darkroom code the camera runs, at each film's default finish: Print Scan, Strength 100 %, Grain Normal, Halation Wide (formerly "Film"), Bloom Normal, Mist Off. Pick A and B, drag the divider, or flip between them. "1:1 detail" is a pixel-for-pixel crop of the 5184 px file, where the grain shows.
